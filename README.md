# ShopFlow

Учебная информационная система интернет-магазина для демонстрации процессов управления разработкой программного обеспечения и возможностей Git.

## Назначение

Проект моделирует каталог товаров, оформление заказов и контроль складских остатков. История репозитория специально отражает последовательную разработку, работу с ветками, разрешение конфликтов, перебазирование, поиск дефекта и перенос отдельных коммитов.

## Архитектура

Основная бизнес-логика находится в `shop.py`, а автоматические проверки — в `test_shop.py`. Такой состав позволяет демонстрировать изменение функционала и подтверждать корректность каждой стабильной версии.

## Командная работа

Изменения участников выполняются в отдельных ветках. Перед объединением разработчик проверяет тесты, публикует ветку и передаёт изменения на проверку через запрос на слияние.
