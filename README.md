# ShopFlow

Учебная информационная система интернет-магазина для демонстрации процессов управления разработкой программного обеспечения и возможностей Git.

## Назначение

Проект моделирует каталог товаров, оформление заказов и контроль складских остатков. История репозитория специально отражает последовательную разработку, работу с ветками, разрешение конфликтов, перебазирование, поиск дефекта и перенос отдельных коммитов.
